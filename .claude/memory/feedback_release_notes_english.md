name: Release 说明用英文
description: GitHub Release 的说明正文（What's New / Downloads）使用英文编写
type: feedback
---

GitHub Release 的说明正文（What's New、Downloads 等）一律使用**英文**编写。

**Why:** Release 面向更广的用户群，用户要求统一英文。

**How to apply:** 执行 `/leo:github-release` 或手写/PATCH Release body 时，正文用英文。注意区分：README 仍双语，git commit message 仍英文，对话仍中文。
